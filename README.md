# Funnuun Storyboard Studio

Standalone 4-stage creative portfolio & production planning workspace:
1. **Stage 01 — Concept Development & Talent Selection**
2. **Stage 02 — Visual Direction**
3. **Stage 03 — Scene Planning**
4. **Stage 04 — Portfolio Presentation**

## Local Development
```bash
npm run check
npm run build
npm start
```

## Vercel Deployment
Configured with `vercel.json` (`buildCommand: npm run build`, `outputDirectory: public`) and `/api/talents` serving safe demo talent profiles with zero production database or credential dependencies.
